# **App Name**: RMJP Rental Landing

## Core Features:

- Hero Section Animation: Animate the text slogan on the hero section using Framer Motion for a modern and engaging introduction.
- Motor Inventory Grid: Display available motorcycles in a grid format on the home page, with key specs visible on each card. On clicking each grid it directs you to a detail page
- Motor Detail Page: Showcase high-resolution photos and standard facilities for each motorcycle.
- Interactive Google Maps Integration: Embed an interactive map displaying the RMJP office location in Jakarta and Bandung.
- WhatsApp Order Form with Conditional Logic: Implement an elegant form to collect renter data. Conditionally show fields based on user input (e.g., Jakarta work duration). Upon submission a summary will be constructed and sent to the provided WhatsApp number.
- Frontend Form Validation: Utilize Zod for robust frontend form validation to prevent XSS attacks and ensure data integrity before submission.
- Bot Protection: Implement a honeypot or similar technique to prevent bot spamming on the submission button.

## Style Guidelines:

- Primary color: Electric Blue (#7DF9FF) for a vibrant and modern feel.
- Background color: Deep Charcoal (#36454F) desaturated for a sleek, premium backdrop.
- Accent color: White Space (#FFFFFF) for clean and crisp text and highlights to create high contrast.
- Body and headline font: 'Poppins' sans-serif for a contemporary, precise feel. Good for short amounts of text but may not be good for long texts.
- Mobile-first design approach, ensuring a fully responsive layout optimized for smartphone users.
- Use subtle scroll-reveal animations and hover effects on motorcycle cards to enhance user engagement.
